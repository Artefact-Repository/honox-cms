# Introduction

Un componente de selección estructurado que presenta cada opción de radio como una tarjeta cliqueable. Es ideal para niveles de precios, planes de suscripción, métodos de pago y cualquier escenario de selección única que requiera énfasis visual.

El componente **RadioCardGroup** está totalmente integrado como bloque `radioCardGroup` en el **Page Builder**, permitiendo a los autores configurar fácilmente la orientación, el color de énfasis de marca y las tarjetas de opciones incluidas.

---

# Usage

Estos ejemplos ilustran cómo los editores de contenido enlazan y estructuran grupos de tarjetas de radio interactivos.

## 1. Grupo de tarjetas de radio básico (disposición vertical)

Un grupo de tarjetas básico con dos opciones. Muestra tarjetas en una lista vertical con un punto de énfasis de marca global.

<DemoPreview>
  <RadioCardGroup defaultValue="standard" colorPalette="blue" interactive>
    <RadioCard value="standard" label="Standard" description="For personal projects" />
    <RadioCard value="pro" label="Pro" description="For small teams" />
  </RadioCardGroup>
</DemoPreview>

```json
{
  "type": "radioCardGroup",
  "defaultValue": "standard",
  "colorPalette": "blue",
  "orientation": "vertical",
  "items": [
    { "value": "standard", "label": "Standard", "description": "For personal projects" },
    { "value": "pro", "label": "Pro", "description": "For small teams" }
  ]
}
```

## 2. Grupo de tarjetas de radio en disposición horizontal

Un grupo de tres tarjetas en disposición horizontal, apto para áreas de formulario compactas, barras laterales de filtros o columnas estrechas. El plan «Standard» viene preseleccionado.

<DemoPreview>
  <RadioCardGroup defaultValue="standard" orientation="horizontal" interactive>
    <RadioCard value="free" label="Free" description="Basic" />
    <RadioCard value="standard" label="Standard" description="Recommended" />
    <RadioCard value="premium" label="Premium" description="Advanced" />
  </RadioCardGroup>
</DemoPreview>

```json
{
  "type": "radioCardGroup",
  "defaultValue": "standard",
  "orientation": "horizontal",
  "items": [
    { "value": "free", "label": "Free", "description": "Basic" },
    { "value": "standard", "label": "Standard", "description": "Recommended" },
    { "value": "premium", "label": "Premium", "description": "Advanced" }
  ]
}
```

## 3. Variante con tarjeta deshabilitada y preseleccionada

Demuestra estados de interacción combinados: una opción preseleccionada y otra deshabilitada (por ejemplo, agotada o no disponible).

<DemoPreview>
  <RadioCardGroup defaultValue="pro" interactive>
    <RadioCard value="basic" label="Basic" description="Starter" />
    <RadioCard value="pro" label="Pro" description="Most popular" />
    <RadioCard value="enterprise" label="Enterprise" description="Currently unavailable" disabled />
  </RadioCardGroup>
</DemoPreview>

```json
{
  "type": "radioCardGroup",
  "defaultValue": "pro",
  "items": [
    { "value": "basic", "label": "Basic", "description": "Starter" },
    { "value": "pro", "label": "Pro", "description": "Most popular" },
    { "value": "enterprise", "label": "Enterprise", "description": "Currently unavailable", "disabled": true }
  ]
}
```

# Props

| Propiedad | Tipo de campo CMS | Predeterminado | Descripción / opciones admitidas |
| --- | --- | --- | --- |
| **Subopciones** (`items`) | `list` | - | Lista de bloques de opciones; cada uno representa una RadioCard (requiere value / label / description). |
| **Valor predeterminado** (`defaultValue`) | `string` | - | Valor de la opción preseleccionada al montar. |
| **Color de énfasis de marca** (`colorPalette`) | `select` | `"blue"` | Paleta de énfasis visual de la tarjeta seleccionada. <br/>• Opciones: blue, green, red, purple, orange, amber, cyan, slate. |
| **Orientación** (`orientation`) | `select` | `"vertical"` | Dirección de disposición en el DOM. <br/>• Opciones: `"vertical"`, `"horizontal"`. |
| **Forzar interactivo** (`interactive`) | `boolean` | `true` | Hidrata el grupo para enlazar eventos de teclado y puntero. |

# Developer Notes & Accessibility

- **Navegación por teclado (Roving tabindex):** El grupo usa el patrón de tabindex móvil. Todo el grupo comparte un punto de tabulación; los usuarios se mueven con las flechas (arriba/abajo o izquierda/derecha según la orientación) y Space o Enter selecciona la opción enfocada.
- **Cumplimiento WAI-ARIA:** El contenedor renderiza roles de radio semánticos nativos (`role="radiogroup"`, `role="radio"`, `aria-checked`), permitiendo a los lectores de pantalla anunciar el grupo como una entidad seleccionable única.
- **Isla de hidratación:** Como diseño avanzado que captura cambios de selección, cercado de foco e interacciones de teclado, RadioCardGroup opera como una isla condicional de Nivel 2 (`"interactive": true`).
