# Introduction

Um componente de seleção estruturado que apresenta cada opção de rádio como um cartão clicável. É ideal para níveis de preços, planos de assinatura, formas de pagamento e qualquer cenário de seleção única que exija ênfase visual.

O componente **RadioCardGroup** está totalmente integrado como bloco `radioCardGroup` no **Page Builder**, permitindo que os autores configurem facilmente a orientação, a cor de ênfase de marca e os cartões de opções incluídos.

---

# Usage

Estes exemplos ilustram como os editores de conteúdo vinculam e estruturam grupos de cartões de rádio interativos.

## 1. Grupo de cartões de rádio básico (layout vertical)

Um grupo de cartões básico com duas opções. Mostra os cartões em uma lista vertical com um ponto de ênfase de marca global.

<DemoPreview>
  <RadioCardGroup defaultValue="standard" colorPalette="blue" interactive>
    <RadioCard value="standard" label="Standard" description="For personal projects" />
    <RadioCard value="pro" label="Pro" description="For small teams" />
  </RadioCardGroup>
</DemoPreview>

```json
{
  "type": "radioCardGroup",
  "defaultValue": "standard",
  "colorPalette": "blue",
  "orientation": "vertical",
  "items": [
    { "value": "standard", "label": "Standard", "description": "For personal projects" },
    { "value": "pro", "label": "Pro", "description": "For small teams" }
  ]
}
```

## 2. Grupo de cartões de rádio em layout horizontal

Um grupo de três cartões em disposição horizontal, adequado para áreas de formulário compactas, barras laterais de filtro ou colunas estreitas. O plano «Standard» vem pré-selecionado.

<DemoPreview>
  <RadioCardGroup defaultValue="standard" orientation="horizontal" interactive>
    <RadioCard value="free" label="Free" description="Basic" />
    <RadioCard value="standard" label="Standard" description="Recommended" />
    <RadioCard value="premium" label="Premium" description="Advanced" />
  </RadioCardGroup>
</DemoPreview>

```json
{
  "type": "radioCardGroup",
  "defaultValue": "standard",
  "orientation": "horizontal",
  "items": [
    { "value": "free", "label": "Free", "description": "Basic" },
    { "value": "standard", "label": "Standard", "description": "Recommended" },
    { "value": "premium", "label": "Premium", "description": "Advanced" }
  ]
}
```

## 3. Variante com cartão desabilitado e pré-selecionado

Demonstra estados de interação combinados: uma opção pré-selecionada e outra desabilitada (por exemplo, esgotada ou indisponível).

<DemoPreview>
  <RadioCardGroup defaultValue="pro" interactive>
    <RadioCard value="basic" label="Basic" description="Starter" />
    <RadioCard value="pro" label="Pro" description="Most popular" />
    <RadioCard value="enterprise" label="Enterprise" description="Currently unavailable" disabled />
  </RadioCardGroup>
</DemoPreview>

```json
{
  "type": "radioCardGroup",
  "defaultValue": "pro",
  "items": [
    { "value": "basic", "label": "Basic", "description": "Starter" },
    { "value": "pro", "label": "Pro", "description": "Most popular" },
    { "value": "enterprise", "label": "Enterprise", "description": "Currently unavailable", "disabled": true }
  ]
}
```

# Props

| Propriedade | Tipo de campo CMS | Padrão | Descrição / opções suportadas |
| --- | --- | --- | --- |
| **Subopções** (`items`) | `list` | - | Lista de blocos de opções; cada um representa uma RadioCard (requer value / label / description). |
| **Valor padrão** (`defaultValue`) | `string` | - | Valor da opção pré-selecionada na montagem. |
| **Cor de ênfase de marca** (`colorPalette`) | `select` | `"blue"` | Paleta de ênfase visual do cartão selecionado. <br/>• Opções: blue, green, red, purple, orange, amber, cyan, slate. |
| **Orientação** (`orientation`) | `select` | `"vertical"` | Direção de disposição no DOM. <br/>• Opções: `"vertical"`, `"horizontal"`. |
| **Forçar interativo** (`interactive`) | `boolean` | `true` | Hidrata o grupo para vincular eventos de teclado e ponteiro. |

# Developer Notes & Accessibility

- **Navegação por teclado (Roving tabindex):** O grupo usa o padrão de tabindex móvel. Todo o grupo compartilha um ponto de tabulação; os usuários se movem com as setas (cima/baixo ou esquerda/direita conforme a orientação) e Space ou Enter seleciona a opção focada.
- **Conformidade WAI-ARIA:** O contêiner renderiza funções de rádio semânticas nativas (`role="radiogroup"`, `role="radio"`, `aria-checked`), permitindo que leitores de tela anunciem o grupo como uma entidade selecionável única.
- **Ilha de hidratação:** Como um layout avançado que captura mudanças de seleção, cercamento de foco e interações de teclado, o RadioCardGroup opera como uma ilha condicional de Nível 2 (`"interactive": true`).
