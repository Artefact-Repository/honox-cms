# Introduction

Eine strukturierte Auswahlkomponente, die einzelne Radio-Optionen als klickbare Karten darstellt. Ideal für Preisstufen, Abo-Modelle, Zahlungsmethoden und alle Single-Select-Szenarien mit starker visueller Betonung.

Die **RadioCardGroup**-Komponente ist als `radioCardGroup`-Block vollständig in den **Page Builder** integriert, sodass Autoren Ausrichtung, Markenakzentfarbe und enthaltene Optionskarten der Gruppe leicht konfigurieren können.

***

# Usage

Diese Beispiele zeigen, wie Redakteure interaktive Radio-Kartengruppen binden und strukturieren.

## 1. Grundlegende Radio-Kartengruppe (vertikales Layout)

Eine einfache Kartengruppe mit zwei Optionen. Zeigt Karten in einer vertikalen Liste mit globalem Markenakzentpunkt.

<DemoPreview>
  <RadioCardGroup defaultValue="standard" colorPalette="blue" interactive>
    <RadioCard value="standard" label="Standard" description="For personal projects" />
    <RadioCard value="pro" label="Pro" description="For small teams" />
  </RadioCardGroup>
</DemoPreview>

```json
{
  "type": "radioCardGroup",
  "defaultValue": "standard",
  "colorPalette": "blue",
  "orientation": "vertical",
  "items": [
    { "value": "standard", "label": "Standard", "description": "For personal projects" },
    { "value": "pro", "label": "Pro", "description": "For small teams" }
  ]
}
```

## 2. Radio-Kartengruppe im horizontalen Layout

Eine horizontal angeordnete Drei-Karten-Gruppe, geeignet für kompakte Formularbereiche, Filter-Sidebars oder schmale Spalten. Der „Standard"-Tarif ist vorausgewählt.

<DemoPreview>
  <RadioCardGroup defaultValue="standard" orientation="horizontal" interactive>
    <RadioCard value="free" label="Free" description="Basic" />
    <RadioCard value="standard" label="Standard" description="Recommended" />
    <RadioCard value="premium" label="Premium" description="Advanced" />
  </RadioCardGroup>
</DemoPreview>

```json
{
  "type": "radioCardGroup",
  "defaultValue": "standard",
  "orientation": "horizontal",
  "items": [
    { "value": "free", "label": "Free", "description": "Basic" },
    { "value": "standard", "label": "Standard", "description": "Recommended" },
    { "value": "premium", "label": "Premium", "description": "Advanced" }
  ]
}
```

## 3. Deaktivierte und vorausgewählte Kartenvariante

Zeigt kombinierte Interaktionszustände: eine Option vorausgewählt, eine andere deaktiviert (z. B. ausverkauft oder nicht verfügbar).

<DemoPreview>
  <RadioCardGroup defaultValue="pro" interactive>
    <RadioCard value="basic" label="Basic" description="Starter" />
    <RadioCard value="pro" label="Pro" description="Most popular" />
    <RadioCard value="enterprise" label="Enterprise" description="Currently unavailable" disabled />
  </RadioCardGroup>
</DemoPreview>

```json
{
  "type": "radioCardGroup",
  "defaultValue": "pro",
  "items": [
    { "value": "basic", "label": "Basic", "description": "Starter" },
    { "value": "pro", "label": "Pro", "description": "Most popular" },
    { "value": "enterprise", "label": "Enterprise", "description": "Currently unavailable", "disabled": true }
  ]
}
```

# Props

| Eigenschaft | CMS-Feldtyp | Standard | Beschreibung / unterstützte Optionen |
| --- | --- | --- | --- |
| **Unteroptionen** (`items`) | `list` | - | Liste von Options-Blöcken; jeder repräsentiert eine RadioCard (benötigt value / label / description). |
| **Vorausgewählter Wert** (`defaultValue`) | `string` | - | Wert der beim Mounten vorausgewählten Option. |
| **Markenakzentfarbe** (`colorPalette`) | `select` | `"blue"` | Visuelle Akzentpalette der ausgewählten Karte. <br/>• Optionen: blue, green, red, purple, orange, amber, cyan, slate. |
| **Ausrichtung** (`orientation`) | `select` | `"vertical"` | Anordnung der Kartengruppe im DOM. <br/>• Optionen: `"vertical"`, `"horizontal"`. |
| **Interaktiv erzwingen** (`interactive`) | `boolean` | `true` | Hydriert die Radio-Gruppe zum Binden von Tastatur- und Zeigerevents. |

# Developer Notes & Accessibility

- **Tastaturnavigation (Roving Tabindex):** Die Kartengruppe nutzt das Roving-Tabindex-Muster. Die gesamte Radio-Gruppe teilt sich einen Tab-Stopp; Nutzer bewegen sich mit den Pfeiltasten (je nach Ausrichtung auf/ab oder links/rechts) zwischen Optionen, Space oder Enter wählen die fokussierte aus.
- **WAI-ARIA-Konformität:** Der Container rendert native semantische Radio-Rollen (`role="radiogroup"`, `role="radio"`, `aria-checked`), sodass Screenreader die Gruppe als eine einzelne auswählbare Entität ansagen.
- **Hydration Island:** Als Advanced-Layout, das Auswahlwechsel, Fokus-Einfriedung und Tastaturinteraktionen abfängt, läuft RadioCardGroup als Tier-2-bedingte Insel (`"interactive": true`).
