# Introduction

一个结构化的选择组件，将各个 Radio 选项呈现为可点击的卡片。它非常适合定价层级、订阅方案、支付方式以及任何需要强视觉强调的单选场景。

**RadioCardGroup** 组件已作为 `radioCardGroup` 区块完全集成到 **Page Builder** 中，使作者能够轻松地为卡片组配置方向、品牌强调色和所包含的选项卡片。

***

# Usage

以下示例展示了内容编辑人员如何绑定和构建交互式单选卡片组。

## 1. 基础单选卡片组（纵向布局）

一个包含两个选项的基础卡片组。演示在垂直列表中排列卡片，并设置全局品牌强调点。

<DemoPreview>
  <RadioCardGroup defaultValue="standard" colorPalette="blue" interactive>
    <RadioCard value="standard" label="Standard" description="For personal projects" />
    <RadioCard value="pro" label="Pro" description="For small teams" />
  </RadioCardGroup>
</DemoPreview>

```json
{
  "type": "radioCardGroup",
  "defaultValue": "standard",
  "colorPalette": "blue",
  "orientation": "vertical",
  "items": [
    { "value": "standard", "label": "Standard", "description": "For personal projects" },
    { "value": "pro", "label": "Pro", "description": "For small teams" }
  ]
}
```

## 2. 横向布局单选卡片组

一个横向排列的三项卡片组，适合紧凑的表单区域、筛选侧边栏或窄栏。默认选中高亮的「Standard」计划。

<DemoPreview>
  <RadioCardGroup defaultValue="standard" orientation="horizontal" interactive>
    <RadioCard value="free" label="Free" description="Basic" />
    <RadioCard value="standard" label="Standard" description="Recommended" />
    <RadioCard value="premium" label="Premium" description="Advanced" />
  </RadioCardGroup>
</DemoPreview>

```json
{
  "type": "radioCardGroup",
  "defaultValue": "standard",
  "orientation": "horizontal",
  "items": [
    { "value": "free", "label": "Free", "description": "Basic" },
    { "value": "standard", "label": "Standard", "description": "Recommended" },
    { "value": "premium", "label": "Premium", "description": "Advanced" }
  ]
}
```

## 3. 禁用与预选卡片变体

演示组合交互状态：预选一项，禁用另一项（例如已售罄或暂不可用）。

<DemoPreview>
  <RadioCardGroup defaultValue="pro" interactive>
    <RadioCard value="basic" label="Basic" description="Starter" />
    <RadioCard value="pro" label="Pro" description="Most popular" />
    <RadioCard value="enterprise" label="Enterprise" description="Currently unavailable" disabled />
  </RadioCardGroup>
</DemoPreview>

```json
{
  "type": "radioCardGroup",
  "defaultValue": "pro",
  "items": [
    { "value": "basic", "label": "Basic", "description": "Starter" },
    { "value": "pro", "label": "Pro", "description": "Most popular" },
    { "value": "enterprise", "label": "Enterprise", "description": "Currently unavailable", "disabled": true }
  ]
}
```

# Props

| 属性 | CMS 字段类型 | 默认值 | 描述 / 支持的选项 |
| --- | --- | --- | --- |
| **子选项** (`items`) | `list` | - | 选项子区块的列表，每个代表一个 RadioCard 元素（需包含 value / label / description）。 |
| **默认选中值** (`defaultValue`) | `string` | - | 挂载时预选选项的 value。 |
| **品牌强调色** (`colorPalette`) | `select` | `"blue"` | 应用于选中卡片的视觉强调调色板。 <br/>• 选项：blue、green、red、purple、orange、amber、cyan、slate。 |
| **布局方向** (`orientation`) | `select` | `"vertical"` | 卡片组在 DOM 中的排列方向。 <br/>• 选项：`"vertical"`、`"horizontal"`。 |
| **强制交互** (`interactive`) | `boolean` | `true` | 对 radio 组进行注水，以绑定键盘和指针事件。 |

# Developer Notes & Accessibility

- **键盘导航（Roving tabindex）：** 卡片组使用 roving tabindex 模式。整个 radio 组共享一个 tab 停靠点；用户使用方向键（上/下或左/右，取决于方向）在选项间移动，Space 或 Enter 选中当前聚焦项。
- **WAI-ARIA 合规性：** 容器渲染原生语义 radio 角色（`role="radiogroup"`、`role="radio"`、`aria-checked`），使屏幕阅读器将卡片组正确播报为单一可选实体。
- **注水孤岛：** 作为一个捕获选择切换、焦点围栏和键盘交互的高级布局，RadioCardGroup 作为 Tier-2 条件性孤岛运行（`"interactive": true`）。
