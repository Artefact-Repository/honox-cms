# Introduction

Un composant de sélection structuré qui présente chaque option radio sous forme de carte cliquable. Idéal pour les niveaux de tarification, les formules d'abonnement, les moyens de paiement et tout scénario de sélection unique nécessitant un fort accent visuel.

Le composant **RadioCardGroup** est totalement intégré en tant que bloc `radioCardGroup` dans le **Page Builder**, permettant aux auteurs de configurer facilement l'orientation, la couleur d'accent de marque et les cartes d'options incluses.

---

# Usage

Ces exemples illustrent comment les éditeurs de contenu lient et structurent des groupes de cartes radio interactifs.

## 1. Groupe de cartes radio de base (disposition verticale)

Un groupe de cartes simple avec deux options. Affiche les cartes dans une liste verticale avec un point d'accent de marque global.

<DemoPreview>
  <RadioCardGroup defaultValue="standard" colorPalette="blue" interactive>
    <RadioCard value="standard" label="Standard" description="For personal projects" />
    <RadioCard value="pro" label="Pro" description="For small teams" />
  </RadioCardGroup>
</DemoPreview>

```json
{
  "type": "radioCardGroup",
  "defaultValue": "standard",
  "colorPalette": "blue",
  "orientation": "vertical",
  "items": [
    { "value": "standard", "label": "Standard", "description": "For personal projects" },
    { "value": "pro", "label": "Pro", "description": "For small teams" }
  ]
}
```

## 2. Groupe de cartes radio en disposition horizontale

Un groupe de trois cartes en disposition horizontale, adapté aux zones de formulaire compactes, barres latérales de filtre ou colonnes étroites. Le plan « Standard » est présélectionné.

<DemoPreview>
  <RadioCardGroup defaultValue="standard" orientation="horizontal" interactive>
    <RadioCard value="free" label="Free" description="Basic" />
    <RadioCard value="standard" label="Standard" description="Recommended" />
    <RadioCard value="premium" label="Premium" description="Advanced" />
  </RadioCardGroup>
</DemoPreview>

```json
{
  "type": "radioCardGroup",
  "defaultValue": "standard",
  "orientation": "horizontal",
  "items": [
    { "value": "free", "label": "Free", "description": "Basic" },
    { "value": "standard", "label": "Standard", "description": "Recommended" },
    { "value": "premium", "label": "Premium", "description": "Advanced" }
  ]
}
```

## 3. Variante avec carte désactivée et présélectionnée

Démontre des états d'interaction combinés : une option présélectionnée, une autre désactivée (par exemple épuisée ou indisponible).

<DemoPreview>
  <RadioCardGroup defaultValue="pro" interactive>
    <RadioCard value="basic" label="Basic" description="Starter" />
    <RadioCard value="pro" label="Pro" description="Most popular" />
    <RadioCard value="enterprise" label="Enterprise" description="Currently unavailable" disabled />
  </RadioCardGroup>
</DemoPreview>

```json
{
  "type": "radioCardGroup",
  "defaultValue": "pro",
  "items": [
    { "value": "basic", "label": "Basic", "description": "Starter" },
    { "value": "pro", "label": "Pro", "description": "Most popular" },
    { "value": "enterprise", "label": "Enterprise", "description": "Currently unavailable", "disabled": true }
  ]
}
```

# Props

| Propriété | Type de champ CMS | Défaut | Description / options prises en charge |
| --- | --- | --- | --- |
| **Sous-options** (`items`) | `list` | - | Liste de blocs d'options ; chacun représente une RadioCard (requiert value / label / description). |
| **Valeur par défaut** (`defaultValue`) | `string` | - | Valeur de l'option présélectionnée au montage. |
| **Couleur d'accent de marque** (`colorPalette`) | `select` | `"blue"` | Palette d'accent visuel de la carte sélectionnée. <br/>• Options : blue, green, red, purple, orange, amber, cyan, slate. |
| **Orientation** (`orientation`) | `select` | `"vertical"` | Direction de disposition dans le DOM. <br/>• Options : `"vertical"`, `"horizontal"`. |
| **Forcer interactif** (`interactive`) | `boolean` | `true` | Hydrate le groupe pour lier les événements clavier et pointeur. |

# Developer Notes & Accessibility

- **Navigation clavier (Roving tabindex) :** Le groupe utilise le modèle de tabindex mobile. Tout le groupe partage un point de tabulation ; les utilisateurs se déplacent avec les flèches (haut/bas ou gauche/droite selon l'orientation) et Space ou Entrée sélectionne l'option focalisée.
- **Conformité WAI-ARIA :** Le conteneur rend des rôles radio sémantiques natifs (`role="radiogroup"`, `role="radio"`, `aria-checked`), permettant aux lecteurs d'écran d'annoncer le groupe comme une entité sélectionnable unique.
- **Îlot d'hydratation :** En tant que mise en page avancée capturant les changements de sélection, l'enclos de focus et les interactions clavier, RadioCardGroup fonctionne comme un îlot conditionnel de Niveau 2 (`"interactive": true`).
