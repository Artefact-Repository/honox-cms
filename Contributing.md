# Contributing

Contributions of any kind are more than welcome. There are two easy ways to get involved:

## 1. Pick up an existing task

1. Browse the open tasks at [Tasks](https://honox.chen.software/tasks).
2. Open a pull request against the repo on [GitHub](https://github.com/Chen-Software/honox-cms/compare).

## 2. Propose your own change

If you have a freeform change in mind that isn't tracked as a task yet:

1. Create a new task `.md` file in `content/tasks/` describing what you're changing and why. Feel free to create more than one task file if it's a large change and/or  create related project(s) in `content/projects/`.
2. Make your code changes alongside it.
3. Open a pull request that includes both the task file and your changes.

Every contribution — big or small — is appreciated.
